## 🧑‍💻 About Me

I'm a **freelance fullstack developer** from Bénin, building web apps, mobile apps, and IoT systems that solve real problems — especially in West Africa. I'm currently finishing my **Licence in Electrical & Computer Engineering (GEI)** at INSTI/UNSTIM while running **Gajone Dev**, my freelance brand serving clients in French-speaking and European markets.

I love turning ideas into shipped products, from Flutter apps to ESP32 firmware to Next.js platforms. I'm driven by the belief that tech built in Africa, for Africa, can compete globally.

## 🚀 Featured Projects

### 🌾 AgriLink
> Flutter marketplace connecting urban consumers with agricultural producers in Cotonou.

- **Stack:** Flutter (Clean Architecture, BLoC, GoRouter) · TypeScript/Express/Prisma · PostgreSQL · Railway
- **Roles:** Client, Producer, Driver, Admin
- **Highlights:** JWT auth, multi-role profiles, designed & prototyped from mockup to production

### 🔥 GAIN Website
> Bilingual showcase site for Gospel Activists International Network.

- **Stack:** Next.js 15 · Framer Motion · Tailwind CSS v4 · Server Components
- **Highlights:** Custom "Flamme Vivante" color palette, smooth animations, FR/EN support

### 🏠 6AX-Tech *(in progress)*
> Smart home hardware startup for West Africa — affordable IoT solutions for property developers.

- **Products:** 6AX Gate · 6AX Power · 6AX Water · 6AX Intercom
- **Stack:** ESP-IDF/FreeRTOS firmware · Custom PCB (KiCad) · Next.js dashboard
- **Highlights:** Full business plan, phased go-to-market strategy targeting Bénin & UEMOA

### 🔒 Smart Door Lock
> IoT smart lock system — engineering school project.

- **Stack:** ESP32-WROOM-32 · FreeRTOS (6-task architecture) · HiveMQ Cloud MQTT/TLS · Fingerprint sensor · Next.js web interface
- **Highlights:** I2C LCD queue, secure cloud communication, biometric enrollment

### 🌱 iVeges
> IoT-powered autonomous irrigation monitoring app (engineering thesis project).

- **Stack:** Flutter · ESP32 master + Arduino Nano slaves · NRF24L01+PA+LNA · Mamdani fuzzy logic
- **Highlights:** WSN architecture, dual-format JSON parsing, BLoC/GoRouter, demo mode

### 📚 Wéman LMS
> Learning Management System with video streaming and PDF certificates.

- **Stack:** Next.js · Drizzle ORM · Better Auth · Inngest · Mux · Docker/PostgreSQL
- **Highlights:** Puppeteer-based certificate generation, ngrok integration
